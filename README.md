# IPTV-List-Colombis
Repositorio de links IPTV de canales colombianos / Colombian channels IPTV links repository

Este repositorio incluye diversos links de canales IPTV colombianos. Solo basta con descargar el archivo .m3u y ejecutarlo con programas como VLC media player o TiviMate.
